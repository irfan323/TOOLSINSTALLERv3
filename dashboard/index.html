⚠️ Catatan: Setiap pengguna memiliki data lokal masing-masing. Untuk berbagi data secara realtime, pilih Firebase atau Supabase.
Cara setup Firebase (gratis):
1. Buka console.firebase.google.com
2. Buat project baru → aktifkan Realtime Database
3. Set rules: { "rules": { ".read": true, ".write": true } }
4. Salin konfigurasi project → paste di form bawah
5. Klik Sambungkan Firebase
Cara setup Supabase (gratis):
1. Buka supabase.com → buat project
2. Buka SQL Editor → jalankan perintah ini:
create table peserta (id text primary key, data jsonb);
alter table peserta enable row level security;
create policy "public" on peserta for all using (true) with check (true);
3. Di Project Settings → API: salin URL dan anon key
4. Paste di form bawah → klik Sambungkan Supabase
